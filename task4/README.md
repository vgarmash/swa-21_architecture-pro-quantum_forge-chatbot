# RAG-ассистент с техниками Few-shot и Chain-of-Thought

Это локальный вопросно-ответный бот (RAG), обученный на знаниях о фэнтезийном мире (Веридония, Окхейвен и др.). Проект демонстрирует использование векторной базы данных ChromaDB, локальной LLM (Flan-T5) и методов промптинга (Few-shot, CoT) для улучшения качества ответов.

## Особенности

*   **RAG (Retrieval-Augmented Generation):** Поиск релевантной информации в базе знаний перед формированием ответа.
*   **Few-Shot Prompting:** Использование примеров问答 для обучения модели в момент запроса.
*   **Chain-of-Thought (CoT):** Модель объясняет ход своих мыслей перед тем, как дать финальный ответ.
*   **Локальное исполнение:** Все вычисления (эмбеддинги и генерация) происходят на вашем компьютере.
*   **Два интерфейса:** Консольный режим (REPL) и Telegram-бот.

## Стек технологий

*   **Python 3.12+**
*   **LangChain** — Оркестрация пайплайнов.
*   **ChromaDB** — Векторная база данных.
*   **HuggingFace Transformers** — Локальные модели:
    *   Эмбеддинги: `sentence-transformers/all-MiniLM-L6-v2`
    *   Генерация: `google/flan-t5-base`
*   **PyTorch** — ML-фреймворк.

## Установка и настройка

### 1. Клонирование и подготовка окружения

Убедитесь, что у вас установлен Python 3.12. Создайте виртуальное окружение и установите зависимости:

```bash
# Создание виртуального окружения (опционально)
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
# venv\Scripts\activate   # Для Windows

# Установка библиотек
pip install -r requirements.txt
```

> **Примечание:** При установке `torch` убедитесь, что у вас установлена версия с поддержкой CUDA, если у вас есть видеокарта NVIDIA. В `requirements.txt` указана базовая версия (CPU).

### 2. Подготовка базы знаний

Для работы бота требуется база данных ChromaDB.

1.  Создайте папку `chroma_db` в корне проекта, если её нет.
2.  Возьмите файл дампа базы данных, который вы использовали ранее.
3.  Если он называется `chroma.sqlite3.txt`, переименуйте его в `chroma.sqlite3`.
4.  Положите файл `chroma.sqlite3` внутрь папки `chroma_db`.

Итоговая структура проекта должна выглядеть так:

```text
/my_rag_project
├── chroma_db/
│   └── chroma.sqlite3       <-- ВАЖНО: База данных должна быть здесь
├── rag_engine.py            <-- Модуль логики
├── run_repl.py              <-- Скрипт консольного бота
├── run_telegram_bot.py      <-- Скрипт Telegram бота
├── requirements.txt
└── README.md
```

## Использование

### Вариант А: Консольный бот (REPL)

Самый простой способ запустить бота и проверить его работу.

1.  Запустите скрипт:
    ```bash
    python run_repl.py
    ```
2.  При первом запуске скрипт загрузит модели эмбеддингов и LLM (это может занять 1-2 минуты).
3.  В появившемся приглашении введите вопрос на **английском языке**.

Пример диалога:
```text
User: What are the names of the Imperial outposts surrounding Oakhaven?
Bot: Step 1: Look for Imperial outposts near Oakhaven in the context.
...
Step 3: These are the names of the outposts surrounding the village.
```

Для выхода введите `exit`.

### Вариант Б: Telegram-бот

Если вы хотите использовать бота через Telegram.

1.  **Создание бота:**
    *   Найдите бота [@BotFather](https://t.me/botfather) в Telegram.
    *   Отправьте команду `/newbot` и следуйте инструкциям.
    *   Сохраните полученный **API Token** (он выглядит как `123456789:ABCdefGHIjk...`).

2.  **Настройка скрипта:**
    *   Откройте файл `run_telegram_bot.py`.
    *   Вставьте ваш токен в переменную `TELEGRAM_TOKEN`:
        ```python
        TELEGRAM_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
        ```

3.  **Запуск:**
    ```bash
    python run_telegram_bot.py
    ```
4.  **Использование:**
    *   Найдите своего бота в Telegram и нажмите `/start`.
    *   Отправляйте вопросы на английском языке.

## Решение проблем

*   **`FileNotFoundError: Database not found`**: Убедитесь, что папка `chroma_db` и файл `chroma.sqlite3` находятся в той же директории, откуда вы запускаете скрипт.
*   **`OSError: Can't load tokenizer`**: Проверьте подключение к интернету при первом запуске (модели должны скачаться кэшироваться). Или проверьте корректность установки `transformers` и `sentence-transformers`.
*   **Медленная работа**: Если вы запускаете на CPU, генерация ответа может занимать 10-20 секунд. Это нормально для локальных моделей без GPU.
*   **Бот отвечает "I don't know" на все вопросы**:
    *   Проверьте, что база данных не пуста (внутри есть таблицы с данными).
    *   Убедитесь, что вы задаете вопросы на английском, так как контекст и промпты на английском.
