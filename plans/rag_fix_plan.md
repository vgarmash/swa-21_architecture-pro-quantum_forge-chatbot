# План исправления RAG-движка для устранения вымышленных ответов

## Проблемы в текущей реализации

1. **Неправильная обработка отсутствия релевантных результатов**
   - Возвращается "Nothing found. Ask another question." вместо "Information is unavailable. Ask another question."

2. **Отсутствие проверки на вымышленные ответы**
   - Функция `_is_fabricated_answer` закомментирована и не используется
   - Нет проверки соответствия ответа контексту

3. **Проблемы с извлечением цитат**
   - Надежность функции `_extract_citations` низкая
   - Не обрабатываются случаи с несколькими цитатами

4. **Недостаточная фильтрация результатов**
   - Не проверяется релевантность найденных документов
   - Используется фиксированное количество результатов k=2

## Решения

### 1. Исправление обработки отсутствующих результатов
- Заменить текст ответа на "Information is unavailable. Ask another question."

### 2. Реализация проверки на вымышленные ответы
- Активировать и улучшить функцию `_is_fabricated_answer`
- Добавить проверку на минимальную длину ответа
- Проверять наличие цитат в ответе
- Проверять корректность номеров цитат

### 3. Улучшение извлечения цитат
- Улучшить функцию `_extract_citations` для более надежного извлечения цитат
- Обрабатывать случаи с несколькими цитатами в формате [1][2] или [1,2]

### 4. Добавление фильтрации результатов по релевантности
- Добавить порог схожести для фильтрации результатов
- Если найденные документы не релевантны, возвращать сообщение об отсутствии информации

### 5. Улучшение промпта
- Сделать инструкции более строгими для предотвращения генерации вымышленной информации

## Технические детали реализации

### Файл: `task4/m/rag_engine.py`

1. **Исправить метод `search`**:
   - Заменить "Nothing found. Ask another question." на "Information is unavailable. Ask another question."
   - Активировать проверку на вымышленные ответы

2. **Улучшить функцию `_is_fabricated_answer`**:
   - Убрать комментарии
   - Улучшить логику проверки
   - Добавить проверку на минимальную длину ответа
   - Добавить проверку на наличие цитат

3. **Улучшить функцию `_extract_citations`**:
   - Улучшить регулярное выражение для извлечения цитат
   - Обрабатывать различные форматы цитат

4. **Добавить фильтрацию результатов по релевантности**:
   - Добавить порог схожести (например, 0.7)
   - Если релевантность ниже порога, возвращать сообщение об отсутствии информации

5. **Улучшить промпт**:
   - Сделать инструкции более строгими
   - Добавить примеры вымышленных ответов для демонстрации
